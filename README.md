# Google Competitive Programming Contests

Solutions to Google's competitive-programming contests — Code Jam, Kick Start, and Hash Code.

## Layout

Solutions are organised by contest (Code Jam / Kick Start / Hash Code) and by year / round.

> Google retired Code Jam and Kick Start in 2023; this archive preserves solutions from the years they ran.

## Languages

Primarily C++ with some Python.
